## Mainnet

| Service | URL |
|---|---|
| JSON-RPC HTTP | `https://rpc1.autheo.com` |
| JSON-RPC HTTP (secondary) | `https://rpc2.autheo.com` |
| JSON-RPC HTTP (tertiary) | `https://rpc3.autheo.com` |
| EVM block explorer | `https://evm-explorer.autheo.com/` |
| EVM block explorer API | `https://evm-explorer.autheo.com/api/v2/` |
| Cosmos explorer | `https://cosmos.autheo.com` |

## Connecting with ethers.js

<Tabs>
  <Tab title="Mainnet">
    ```javascript
    import { ethers } from "ethers";

    const provider = new ethers.JsonRpcProvider("https://rpc1.autheo.com");
    const network = await provider.getNetwork();
    console.log(network.chainId); // 2127n
    ```
  </Tab>

## WebSocket connections

<Warning>
**Public WebSocket endpoints are not currently offered** on Mainnet or Testnet. The public RPC hosts serve HTTP JSON-RPC only.

For real-time updates, poll the HTTP RPC endpoints above, or run your own node, where the EVM WebSocket port is available locally (see the [self-hosting guide](/validator-program/self-hosting-guide)).

If your project needs a public WebSocket endpoint, let us know on [Discord](https://discord.gg/McEEeXGGya) so the team can gauge demand.
</Warning>

On a node you run yourself, connect to the local WebSocket port:

```javascript
// Self-hosted node (8546 is the default EVM WebSocket port)
const wsProvider = new ethers.WebSocketProvider("ws://127.0.0.1:8546");
```

<Note>
If you need dedicated node access with higher rate limits or guaranteed uptime, see [managed hosting options](/validator-program/hosting-options) from approved providers such as InfStones and Zeeve.
</Note>
